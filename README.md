# The Gate Bible

Shared worldbuilding codex for an SL roleplay set after Baldur's Gate 3 (from 1492 DR).

- **App:** https://the-gate-team.github.io/the-gate-bible/
- **Hosting:** GitHub Pages, served from `index.html` on the `main` branch.
- **Data:** stored in Supabase (project `the-gate-bible`). Only emails on the Team list can sign in and read or edit.

The page contains the Supabase project URL and its public "anon" key. This is expected: the key is meant to be public, and access to the data is enforced by the database's row-level security rules.
